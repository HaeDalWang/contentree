# Helmfile 순차 설치·검증 프로세스

클러스터 정상 확인 후, Rook-Ceph → Ingress-Nginx → 나머지 순으로 설치한다.  
실행 위치: **kubespray-contentree-1.29-1.31/helmfile** (values는 상대경로 `../values` 사용).

---

## 사전 확인

```
helm plugin install https://github.com/databus23/helm-diff
```

```bash
# helm-diff 플러그인 (helmfile apply/diff 시 사용, 없으면 "unknown command diff" 발생)
helm plugin install https://github.com/databus23/helm-diff
# 클러스터·노드 정상
kubectl get nodes
kubectl get pod -A | grep -v Running
```

---

```
cd kubespray-contentree-1.29-1.31/helmfile
```

## 1단계: Ingress-Nginx

```bash
helmfile -l name=ingress-nginx apply
```

- 확인: `kubectl get pod -n ingress-nginx` → controller Running.

---

## 2단계: Rook-Ceph (Operator)

```bash
helmfile -l name=rook-ceph apply
```

- 확인: `kubectl get pod -n rook-ceph` → operator Running.

---

## 3단계: Rook-Ceph Cluster

```bash
helmfile -l name=rook-ceph-cluster apply
```

- OSD·몬 기동 대기 후 확인:
  - `kubectl get pod -n rook-ceph`
  - `kubectl get cephcluster -n rook-ceph` (Ready)
  - 필요 시: `kubectl -n rook-ceph exec -it deploy/rook-ceph-tools -- ceph status`

---

## 4단계: 나머지 릴리스

1~3단계까지 적용한 뒤, 전체 적용 한 번으로 나머지 설치 (의존성 순서는 helmfile이 처리):

```bash
helmfile apply
```

또는 릴리스별로 순서 지정해서 적용:

```bash
helmfile -l name=metrics-server apply
helmfile -l name=kube-prometheus-stack apply
helmfile -l name=x509-certificate-exporter apply
helmfile -l name=loki-stack apply
helmfile -l name=minio apply
helmfile -l name=velero apply
helmfile -l name=argocd apply
```

---

## 전체 재적용 (이미 설치된 환경)

```bash
cd kubespray-contentree-1.29-1.31/helmfile
helmfile apply
```

---

## 유용한 명령어


| 목적          | 명령어                                                    |
| ----------- | ------------------------------------------------------ |
| 설치할 릴리스만 플랜 | `helmfile diff` (helm-diff 플러그인 필요) 또는 `helmfile plan` |
| 릴리스 목록      | `helmfile list`                                        |
| 특정 릴리스만 삭제  | `helmfile -l name=rook-ceph-cluster destroy`           |
| 상태 확인       | `helmfile status`                                      |
