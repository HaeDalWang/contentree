사용 하기

1. cd terraform-contentree-1.29
2. terraform init
3. terraform apply

콘솔에서 ansible-controller의 접속 세션매니저

ec2안에서

1. sudo passwd ubuntu
2. su ubuntu
3. cd
4. git clone [https://github.com/HaeDalWang/contentree.git](https://github.com/HaeDalWang/contentree.git)
5. cd contentree/kubespray-contentree-1.29-1.31
6. ./init-env.sh
7. newgrp docker

도커 설치 확인

1. docker ps

로컬 PC에서 > 앤서블 컨트롤러로 키복사 (해당키로 모든 노드/마스터에 ansible사용 예정)

1. scp -i ~/.ssh/saltware.pem ~/.ssh/saltware.pem ubuntu@<앤서블 배스쳔 IP>:/home/ubuntu/.ssh/id_rsa

다시 ec2

복사한 id_rsa 키 확인

1. ls ~/.ssh
2. mkdir artifacts

큐브스프레이 환경 구성

1. ./kubespray.sh
2. docker exec -it kubespray bash
3. ansible all -i inventory/inventory.yaml -m ping

확인되면 클러스터 배포 시작

```
ansible-playbook -i inventory/inventory.yaml \
--extra-vars "@inventory/variables-1.29.yaml" \
--become \
--become-user=root \
cluster.yml
```

설정파일 복사

1. cd artifacts
2. mkdir ~/.kube
3. sudo cp ./admin.conf ~/.kube/config

노드 확인

1. kubectl get node
2. exit

컨테이너 박에서

1. cd /home/ubuntu/contentree/kubespray-contentree-1.29-1.31/artifacts
2. mkdir ~/.kube
3. sudo chmod 777 admin.conf
4. sudo chmod 777 kubectl
5. sudo cp admin.conf ~/.kube/config
6. sudo cp kubectl /usr/local/bin/kubectl

자동완성

1. echo "source <(kubectl completion bash)" >> ~/.bashrc
2. source ~/.bashrc

재설정 및 재적용

{  
ansible-playbook -i inventory/inventory.yaml
