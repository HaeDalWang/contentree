## 3. Rook-Ceph (POC 주의)

- **rook-ceph**, **rook-ceph-cluster**는 노드에 `role: storage`(mvd-kubest01~03) 및 디스크(sdb 등)가 있어야 동작함.
- 현재 POC는 **스토리지 노드 없음** → rook-ceph-cluster 배포 시 Pod가 스케줄되지 않음.
- **선택지:**  
  - POC에서 Ceph 불필요 시: helmfile에서 rook-ceph, rook-ceph-cluster 릴리스를 주석 처리.  
  - 스토리지 노드 추가 후: 인벤토리/노드 라벨 및 rook values 복원 후 재배포.

## 4. Helmfile

- **opensearch** 및 **fluent-bit-opensearch**, **fluent-bit-all-service-opensearch**  
  - opensearch 레포/values 없음 → helmfile에서 해당 릴리스 주석 처리해 둠.  
  - 사용 시 opensearch Helm 레포 추가 및 `values/opensearch.yaml` 작성 후 주석 해제.
- **실행 경로:** 프로젝트 루트(kubespray-contentree-1.29-1.31)에서  
`helmfile -f helmfile/helmfile.yaml apply`  
로 실행하면 `values/` 경로가 올바르게 잡힘.

## 5. Proxy (dev-mkube-proxy.joins.seungdobae.com:3128)

- argocd, kube-prometheus-stack, loki-stack, harbor 등에 HTTP/HTTPS proxy 설정이 들어 있음.
- POC에 해당 프록시가 없으면 배포·이미지 pull 등이 실패할 수 있음.  
  - 프록시 미사용 시: 각 values에서 `HTTP_PROXY`/`HTTPS_PROXY` 제거 또는 빈 값으로 설정 후 적용.
